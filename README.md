# Pakari · Landing page

Base inicial de una landing page para vender barras de chocolate Pakari, con un estilo inspirado en apple.com. Está pensada primero para el celular.

## Cómo verla

Abre `index.html` en el navegador.

## Lo que hay por ahora

- Menú superior translúcido, que en el celular se convierte en menú hamburguesa.
- Portada (hero) con titular, texto y botones.

## Próximos pasos

1. Poner una foto real del producto en lugar del emoji 🍫.
2. Agregar la sección "Origen".
3. Agregar la sección "Sabores".
4. Agregar la sección "Comprar".
